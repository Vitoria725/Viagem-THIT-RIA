Configurar a senha do Radar

Esta página roda só no seu navegador. A senha nunca sai daqui e não é enviada para ninguém, nem para o Claude. Faça isso uma única vez.

1. Escolha a senha do site

Use pelo menos 12 caracteres. Você e o Thiago vão usar essa senha para entrar. Se ela for perdida, é preciso refazer esta configuração.

2. Dois arquivos para o repositório (podem ser enviados ao Claude)

Eles não revelam nada sem a senha. Baixe e envie os dois para o Claude, ou coloque você mesma na pasta keys/ do repositório.

3. Segredo para o e-mail (só no GitHub, nunca envie a ninguém)

Este texto abre os alertas para enviar por e-mail. Cole apenas no GitHub, em Settings → Secrets and variables → Actions → New repository secret, com o nome ALERT_PRIVATE_KEY. Depois feche esta página.
  1. No mesmo lugar, crie também SMTP_USER (o Gmail que vai enviar), SMTP_PASS (a senha de app de 16 letras desse Gmail) e EMAIL_TO (os dois e-mails separados por vírgula).
  2. A senha de app se cria em myaccount.google.com → Segurança → Verificação em duas etapas → Senhas de app.
